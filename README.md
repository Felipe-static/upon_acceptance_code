# Reproducible Code — Energy Generation Forecasting & Dispatch Optimization

Companion code for the paper published in *Energy Conversion and Management*:

> **Forecast-informed daily energy dispatch for cost and emission reduction: Evidence from an emerging economy power system**  
> *Energy Conversion and Management*, 2026.  
> DOI: [10.1016/j.enconman.2026.121611](https://doi.org/10.1016/j.enconman.2026.121611)

This repository provides a self-contained toy case for the **Valparaíso region** of Chile demonstrating the two-stage pipeline described in the paper:

1. **LSTM forecasting** — daily electricity generation prediction
2. **Multi-objective LP dispatch** — cost and emissions minimization using the forecast as demand signal

## Data

The raw generation dataset (`generacion_total.parquet`, ~143 MB) is too large to host on GitHub. Place it inside the `data/` folder before running Stage 1:

```
upon_acceptance_code/
├── data/
│   └── generacion_total.parquet    ← place here
└── ...
```

**Download:** [energiaabierta.cl](https://energiaabierta.cl/visualizaciones/generacion-bruta/) — hourly electricity generation records for all Chilean power plants (2000–2023), published by the National Electricity Coordinator (CEN / CNE).

> If you only want to run the **LP optimization notebook** (Stage 2), no download is needed — `data/predictions_valparaiso_2023.parquet` is already included.

## How to Run

Run the notebooks **in order**:

### 1. Forecast (`Forecast_total_generation.ipynb`)

- Filters Valparaíso region data, aggregates to daily totals
- **Normalization:** z-score (StandardScaler), fit on training split only (2016–2021)
- **Look-back window:** 30 days
- **Hyperparameters:** Optuna Bayesian (TPE) search — Table 4 of the paper (search is commented out, ~30 min on CPU for 50 trials)
- **Training:** up to 200 epochs with early stopping (patience = 20)
- Saves checkpoint to `models/lstm_valparaiso.pt`
- Saves predictions to `data/predictions_valparaiso_2023.parquet`
- Saves all figures to `figures/`

### 2. LP Optimization (`Modelation_linear_programming.ipynb`)

- Loads LSTM forecasts as daily demand signal
- Solves multi-objective LP (α·cost + β·emissions) using PuLP/CBC
- **BESS parameters:** 10,000 MWh capacity, 2,500 MWh/day charge/discharge rate, η = 0.92, S₀ = 5,000 MWh
- Saves all figures to `figures/`

## Key Results (Valparaíso, 2023 test set)

| Metric | Value |
|---|---|
| Forecast RMSE | 3,740.9 MWh |
| Forecast MAPE | 12.64 % |
| Dispatch periods | 304 days |
| Solver | PuLP / CBC (open-source) |
| Objective weights | α = 0.9 (cost), β = 0.1 (emissions) |
| Total operational cost | USD 935,223,361 |
| Total CO₂e emissions | 8,416,423,294 kg |

> **Note on reproducibility:** Results are close but not identical to the paper's national-scale values (RMSE = 3,626.8 MWh, MAPE = 10.98%) because the paper's full analysis covered all 14 Chilean regions simultaneously. Minor deviations also arise from stochastic LSTM initialization and CPU vs. GPU floating-point ordering. The methodology is identical — see Section 6.1 of the Forecast notebook for details.
